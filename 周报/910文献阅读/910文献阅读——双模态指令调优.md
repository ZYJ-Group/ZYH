目前的大模型，比如 LLaVA、Qwen-VL，能同时看图和人话，图像描述、视觉定位等任务。但现实中任务是一个接一个来的，不是一次性把所有数据混在一起训练。所以先学习一样再学习另外一样，大模型处理任务存在灾难性遗忘问题，对于让大模型处理图像-文本问题这方面具有十分有价值的研究。

双模态引导的 Prompt 学习框架，就是去给模型增加提示向量，Prompt Learning，



​             本文主要是针对于使用多模态模型中出现的灾难性遗忘（在处理任务时忘记了旧任务）以及计算复杂度过高（每来一个任务就有新的参数模块）的问题，创建一套持续指令微调框架，既不忘旧知识，又绝不增加额外推理负担

双模态，文本与视觉

![image-20260809062401055](image-20260809062401055.png)

第一步，建立提示，为每一个任务分别建立专属词，并且通过轻量化投影转为原型特征

第二步，当新的任务出现时，利用clip编码器，提取到当前输入图像视觉特征以及指令文本特征

第三步，计算出原型特征与输入特征相似度，选取到最为相似的提示（减少计算量），与视觉特征投影以及文本分词一同送入推理模型

论文的学习对于后续发展，多模态持续学习是热点，且实际部署很需要，并且不搞太复杂的结构，核心就是 Prompt + 双模态相似度。如果后续需要改进或者提升的方面主要是只缓解遗忘，不促进对未见任务的“前向迁移”

此论文，就是教多模态大模型“按顺序学很多任务时，用图像和文字两个线索，挑出最相关的旧任务 Prompt 来帮忙，从而既不忘旧知识，又不让计算量随任务数爆炸。



### 二、Fine-Grained Task Planning for Service Robots  Based on Object Ontology Knowledge  via Large Language Models，IEEE ROBOTICS AND AUTOMATION LETTERS, VOL. 9, NO. 8, AUGUST 2024

### Author：Xiaodong Li，Guohui Tian

### keywords：Task Planning，Exceptional Task Planning，LLM

阅读时间：2026.9.10

**自我认识：**

本项目主要针对于机器人任务规划方面，主要是改进传统方法规则库或者逻辑库实现的机器人任务规划，因为这两种方法对于任务实现的主体属性缺少认识，忽略掉了其对于任务本身执行的精细，比如任务目标是纸杯，机器人手臂却只能提取到夹取纸杯的任务，但是需要多大的力，需要用什么姿态去完成夹取任务没有概念。所以这里提出了FGTP的框架。

这框架将任务分成三个过程

![image-20260805034420688](image-20260805034420688.png)

第一是文本图像信息提取，针对于指令，去提取指令所蕴含的信息，比如输入的是将桌上蓝色纸杯移动到厨房，那么能够提取到桌子，蓝色，纸杯，厨房等因素，这需要自己构建类别去完成元素的分类标签以及各类别所占权重，减少小影响因素的影响。

第二是真实图像识别，对于真实场景的识别，利用yolov8去实时检测当前空间，物体的状态，比如识别到桌子的水杯信息。然后利用三元组去生成逻辑关系，clip模型去对齐真实属性与预期属性来进一步判断。

第三是任务约束，对于物体的属性，去选择合适的状态来完成，比如调节握力，方向等

如果不满足当前状态，去找到替代品，用相似度来判断

总之这篇论文的核心是——用物体本体知识补足 LLM 的常识，让服务机器人不仅知道“先做什么后做什么”，还知道“这个物体是什么状态、有什么属性、该怎么抓、坏了用什么替代”，从而生成更细粒度、更可执行的任务规划。
